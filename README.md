# ArmyVArmy

A 2D, mobile-first **roguelite auto-battler** in the spirit of *Slay the Spire* — but every
encounter is a **real-time battle between your army and an AI army**. Win to advance through a map;
lose a single battle and the run is over (permadeath). Between battles you manage a roster: pick
units, arrange your starting formation, buy armor/weapon/ability upgrades, apply buffs, and heal
wounded survivors. Wounds **persist between battles**, so healing is a meaningful spend.

- **Engine:** Unity 6 LTS — 2D URP
- **Platforms:** Android first, iOS second — **landscape** orientation
- **Scale:** real-time auto-battles of **100–300 units per side**
- **Status:** design complete; **no Unity project committed yet**. Start with the **vertical slice**.

## Using this repo with Claude Code locally

Clone the repo, open a terminal in it, and run `claude`. A good first prompt:

> Read CLAUDE.md and Docs/PLAN.md, then start **Phase 1 (Project Bootstrap)** from Docs/ROADMAP.md.
> Create the Unity project structure and the files for that phase only, then stop so I can open it in
> the Unity editor and verify.

Build **one phase at a time** and press Play in the Unity editor to verify each before moving on.

## Why the Unity project isn't in the repo yet

A valid Unity project (`ProjectSettings/`, `Assets/`, `Packages/`) must be generated by the Unity
editor on your machine. This repo ships the **design, roadmap, and agent instructions**; Phase 1 of
the roadmap walks you (or Claude Code, locally) through creating the actual Unity project and
committing it.
